# Дизайн: система, экраны, состояния

В ТЗ v1 дизайн описан одним абзацем: «тёмная тема, один акцент, без градиентов,
цена до запуска, честный прогресс, мобильная версия». Направление верное, но это
не спецификация — по ней нельзя собрать интерфейс и нельзя проверить результат.
Здесь — то, чего не хватало.

---

## 1. Принципы

**Интерфейс — редактор, а не форма.** Пользователь не «заполняет параметры и отправляет»,
а работает с результатом: видит его, правит, повторяет. Форма — промежуточное состояние
пустого редактора.

**Результат крупнее настроек.** Центр экрана всегда занимает холст. Параметры — сбоку
и сворачиваются. На мобильном параметры вообще не видны, пока их не позвали.

**Цена до нажатия, всегда.** На кнопке запуска — стоимость в кредитах и рублях.
Под кнопкой — остаток после операции. Никаких сюрпризов постфактум.

**Ожидание объяснено.** Генерация занимает 10–60 секунд — это вечность в вебе.
Показываем этап, позицию в очереди и диапазон времени. Спиннер без числа —
худшее из возможных решений.

**Ошибка = что делать дальше.** Не «Ошибка 500», а «Провайдер не ответил. Кредиты
вернулись на баланс. Попробовать снова?» с кнопкой.

**Целевая аудитория работает с телефона.** Селлер фотографирует товар и тут же его
обрабатывает. Мобильный макет проектируется первым, десктоп — расширение.

## 2. Токены

Единственный источник — `packages/ui/tokens.css`, экспорт в Tailwind-конфиг.
Никаких цветов в компонентах.

### 2.1 Цвет

Тёмная тема — основная, светлая закладывается сразу как второй слой токенов,
чтобы не переписывать компоненты позже.

```css
:root {
  /* Поверхности */
  --bg-0:      #0B0C0E;  /* фон приложения */
  --bg-1:      #131519;  /* панели, карточки */
  --bg-2:      #1A1D22;  /* поднятые элементы, hover */
  --bg-inset:  #08090B;  /* холст под изображением */
  --border:    #262A31;
  --border-strong: #363C45;

  /* Текст */
  --text-0:    #F2F4F7;  /* заголовки, основной */
  --text-1:    #A7AEBA;  /* вторичный */
  --text-2:    #6B7280;  /* подписи, disabled */

  /* Единственный акцент */
  --accent:       #4F7DFF;
  --accent-hover: #3D6BF0;
  --accent-weak:  #1B2540;  /* фон бейджей и выделений */
  --on-accent:    #FFFFFF;

  /* Статусы */
  --success: #2FB67C;
  --warning: #E0A93B;
  --danger:  #E5484D;
  --info:    var(--accent);

  /* Радиусы */
  --r-sm: 6px;  --r-md: 10px;  --r-lg: 14px;  --r-full: 999px;
}
```

Правила:

* **Один акцент.** Синий — только действие и выделение. Успех/ошибка — статусные цвета,
  они не участвуют в оформлении.
* **Градиентов нет.** Глубина создаётся поверхностью и границей, не тенью:
  в тёмной теме тени почти не читаются. Тень допустима только у всплывающих слоёв.
* **Контраст AA обязателен.** `--text-1` на `--bg-1` даёт 7.1:1, `--text-2` на `--bg-1` —
  4.6:1 (нижняя граница, только для подписей). Проверка контраста — часть CI
  (скрипт по токенам, а не глазами).
* Акцент на белом тексте: `--accent` + `--on-accent` = 4.9:1 — проходит для кнопок.

### 2.2 Типографика

Кириллица требует шрифта, который в неё умеет. Inter приемлем, Golos Text —
лучше по рисунку кириллицы и бесплатен.

```
Шрифт:  'Golos Text', 'Inter', system-ui, sans-serif
Цифры:  font-variant-numeric: tabular-nums  — обязательно для цен, балансов, таймеров
```

| Роль | Размер / интерлиньяж | Начертание |
|---|---|---|
| Display | 40 / 46 | 600 |
| H1 | 32 / 38 | 600 |
| H2 | 24 / 30 | 600 |
| H3 | 20 / 26 | 600 |
| Body | 16 / 24 | 400 |
| Body S | 14 / 20 | 400 |
| Caption | 12 / 16 | 500 |

Русская типографика — часть определения готовности:
кавычки «ёлочки» (внутренние „лапки“), тире — длинное с неразрывным пробелом слева,
неразрывный пробел перед `₽` и между числом и единицей («10 кредитов»),
разряды числа разделяются тонким неразрывным пробелом («1 490 ₽»).
Реализуется утилитой `typo()` в `packages/shared`, применяется на весь пользовательский текст.

### 2.3 Сетка и пространство

Шаг 4 px, шкала `4 8 12 16 24 32 48 64`.
Контейнер сайта 1200 px, кабинет — на всю ширину с минимумом 320 px.
Брейкпоинты: `sm 640`, `md 768`, `lg 1024`, `xl 1280`.

### 2.4 Движение

Быстро и незаметно: 120 мс для наведения, 200 мс для появления панелей,
`cubic-bezier(0.2, 0, 0, 1)`. Единственная заметная анимация — появление
готового результата (плавное проявление 300 мс), потому что это момент ценности.
`@media (prefers-reduced-motion: reduce)` отключает всё, кроме смены непрозрачности.

│            │                                    │                    │

│ Рецепты    │   │                          │     │  Формат      ▾     │
│ История    │   │      результат / дроп     │     │  Референс   [+]    │
│ Проекты    │   │                          │     │  Кол-во    1 2 4   │
│ Брендкит   │   └──────────────────────────┘     │                    │
│ Консультант│                                    │  ─────────────     │
│            │   [ промпт …                    ]  │  Итого   10 кр     │

Мобильный: рельс — нижняя навигация из 4 пунктов (Генерация, История, Рецепты, Профиль),
параметры — bottom sheet по кнопке «Настройки», промпт и кнопка запуска закреплены снизу
над клавиатурой.

## 4. Ключевой экран: генерация

### 4.1 Поле промпта

* Автовысота, максимум 6 строк, дальше скролл.
* `Cmd/Ctrl+Enter` — запуск, `Esc` — снять фокус.
* Под полем — чипы быстрых сценариев: «Фон удалить», «На белом фоне», «На модели»,
  «Инфографика», «Сцена в интерьере». Клик по чипу — не вставка текста, а выбор рецепта.
* Пустое состояние поля — не заглушка «Введите промпт», а три карточки-примера
  с реальными изображениями до/после. Пользователь чаще нажимает пример, чем печатает.

### 4.2 Выбор формата — площадками, а не пикселями

Селлер не знает, что WB требует 900×1200. Он знает, что делает карточку для WB.

```
[ WB карточка 3:4 ] [ Ozon 1:1 ] [ Сторис 9:16 ] [ VK пост 4:5 ] [ Свой размер ]
```

Под выбранным — мелкая подпись с фактическим разрешением. Требования площадок
живут в данных, а не в коде: меняются без релиза.

### 4.3 Кнопка запуска

```
┌───────────────────────────────────────────┐
│      Сгенерировать · 10 кр ≈ 10 ₽         │
└───────────────────────────────────────────┘
   Останется 330 кр · хватит на 33 генерации
```

Состояния кнопки:

| Условие | Вид |
|---|---|
| Всё готово | акцентная, активна |
| Промпт пуст | неактивна, подпись «Опишите, что нужно» |
| Кредитов не хватает | текст «Пополнить на 40 кр», ведёт на оплату, промпт сохраняется |
| Лимит конкурентности | «В работе 3 из 3 · подождите» с обратным отсчётом |
| Стоп-кран или все провайдеры недоступны | неактивна + баннер `maintenanceMessage` |

Дешёвая, но важная деталь: при нехватке кредитов **не** показывать модалку «купите» —
показывать, сколько именно не хватает и сколько это стоит.

### 4.4 Прогресс

Четыре состояния, каждое со своим текстом и своей полосой:

| Этап | Что показываем |
|---|---|
| В очереди | «В очереди · 3-я · примерно 20–40 с» — позиция и диапазон из `p50/p90` |
| Генерация | полоса с оценкой, «Обычно занимает 25 с» |
| Сохранение | «Сохраняем результат» — забор в S3, обычно доли секунды |
| Готово | плавное проявление изображения |

Особые случаи:

* Превысили `p90` → «Дольше обычного, ждём ответа провайдера». Честно и без паники.
* `DEFERRED` → «Сервис провайдера временно недоступен. Кредиты не списаны,
  задача продолжится автоматически» + кнопка «Отменить и вернуть кредиты».
* `ERROR` → «Не получилось. **10 кредитов вернулись на баланс.**» + «Повторить».
  Возврат кредитов — самая важная часть сообщения, он выделен.
* `BLOCKED` → «Запрос не прошёл проверку. Кредиты не списаны.» Причина — общая
  формулировка без раскрытия правил фильтра.

### 4.5 Работа с результатом

Под изображением — панель действий, а не контекстное меню:

```
[ Скачать ] [ ⭐ ] [ Ещё вариант · 10 кр ] [ Правки ▾ ] [ В проект ▾ ]
```

**Правки итерациями** — чипы, а не переписывание промпта:
«светлее», «темнее», «вертикально», «убрать текст», «крупнее товар», «сменить фон».
Каждый чип — новая генерация с наследованием параметров и родителем в `Generation.parentId`.
Цена правки показывается на чипе.

**Сравнение** для редактирующих моделей — слайдер «до/после» поверх одного изображения,
не две картинки рядом: на мобильном рядом ничего не разглядеть.

**Несколько вариантов** — сетка 2×2 с быстрым выбором; невыбранные не удаляются,
но и не занимают ленту.

## 5. История

* Виртуализированная сетка (`@tanstack/virtual`), карточка = `THUMB` в AVIF 320/640.
  **Никогда** не отдавать в ленту мастер-файлы: это и деньги за трафик S3,
  и мёртвый интерфейс на мобильной сети.
* Фильтры: проект, модель, статус, избранное, диапазон дат. Состояние фильтров — в URL.
* Карточка при наведении показывает промпт, цену и время; клик — открывает результат
  в том же рабочем пространстве, с восстановлением всех параметров («повторить и изменить»).
* Ошибочные генерации в ленте видны, с бейджем «кредиты возвращены» — скрывать их
  нельзя, пользователь должен видеть, что ему вернули деньги.
* У файлов с истекающим сроком хранения (FREE) — счётчик «удалится через 3 дня»
  и кнопка «сохранить навсегда» → апгрейд.

## 6. Состояния, которых обычно забывают

Для каждого экрана обязательны все шесть. Отсутствие любого — незакрытая задача.

| Состояние | Требование |
|---|---|
| Пустое | не «нет данных», а следующий шаг с кнопкой |
| Загрузка | скелетоны той же геометрии, что и контент; без «прыжка» макета |
| Частичная загрузка | контент показывается по мере готовности, баланс — отдельно от ленты |
| Ошибка | причина + действие + сохранение введённого |
| Оффлайн | баннер и очередь действий, промпт не теряется |
| Отказано | понятная причина: лимит, тариф, модерация — с путём решения |

## 7. Микрокопирайт

Правила:

* Без «Упс!», «Что-то пошло не так», восклицательных знаков в ошибках.
* Всегда называть сумму и всегда — судьбу денег. «Кредиты вернулись» важнее описания сбоя.
* Обращение на «вы» со строчной.
* Единый словарь: **кредиты** (не токены, не монеты), **генерация** (не запрос),
  **рецепт** (не пайплайн), **проект** (не папка).

Примеры:

| Плохо | Хорошо |
|---|---|
| Ошибка генерации | Не получилось создать изображение. 10 кредитов вернулись на баланс. |
| Недостаточно средств | Не хватает 40 кредитов. Пополнить на 299 ₽ (300 кредитов)? |
| Загрузка… | Генерируем · обычно 25 с |
| Ваш запрос отклонён | Запрос не прошёл проверку. Кредиты не списаны. |

## 8. Доступность

* Контраст AA, проверяется скриптом по токенам в CI.
* Видимое кольцо фокуса: `outline: 2px solid var(--accent); outline-offset: 2px`.
  Убирать `outline` запрещено.
* Цели нажатия ≥ 44×44 px на мобильном.
* Вся генерация доступна с клавиатуры; горячие клавиши: `Cmd+Enter` — запуск,
  `G` — галерея, `/` — фокус в промпт, `Esc` — закрыть панель.
* `aria-live="polite"` на область статуса генерации — смена этапа объявляется
  экранным читателем.
* У результата — `alt` из промпта пользователя (усечённый), у декоративных — `alt=""`.
* `prefers-reduced-motion` уважается.
* Никакой информации только цветом: статус всегда дублируется текстом или иконкой.

## 9. Производительность фронтенда

Бюджеты — часть приёмки, измеряются на 4G / mid-range Android:

| Метрика | Порог |
|---|---|
| LCP главной | ≤ 2.0 с |
| LCP кабинета | ≤ 2.5 с |
| INP | ≤ 200 мс |
| CLS | ≤ 0.05 |
| JS первого экрана | ≤ 200 КБ gzip |

Средства: серверные компоненты по умолчанию, клиентские — только там, где есть
интерактивность; изображения только через `next/image` с S3-loader'ом и AVIF;
шрифт `next/font` с `display: swap` и подмножеством кириллицы; ленты — виртуализация;
скелетоны вместо спиннеров.

## 10. Вотермарк

Не поверх всего кадра и не «крестом» — это делает превью бесполезным и раздражает.
Полупрозрачная плашка в правом нижнем углу: логотип + домен, высота 6 % кадра,
непрозрачность 70 %, тёмная подложка для читаемости на светлых фото.

Наносится на отдельный файл `OutputFile(kind = WATERMARKED)`; мастер хранится чистым.
Апгрейд тарифа открывает мастер без перегенерации — это и техническое решение,
и продающий аргумент: «уже сгенерированное станет чистым сразу после оплаты».

## 11. Публичный сайт

Задача — не рассказать о сервисе, а дать попробовать.

**Первый экран:** заголовок с конкретной пользой, поле промпта прямо в hero,
две-три кнопки-сценария. Ниже сгиба — примеры до/после на реальных товарах
(не абстрактные арты: аудитория — селлеры, им нужно узнать свой товар).

**Гостевой сценарий:** ввод → капча → генерация с вотермарком → результат.
На результате: «Скачать без вотермарка» → регистрация → **результат уже в аккаунте**.
Перенос результата гостя в аккаунт — не мелочь, а главный конверсионный крючок:
пользователь не начинает заново.

**Страницы инструментов** (SEO): одна задача — одна страница, рабочий инструмент
сверху, ответ на вопрос ниже. Шаблон и правила уникальности — в `06-marketing.md`.

**Тарифы:** три колонки, средняя выделена как рекомендуемая, годовая оплата
переключателем с явной экономией. Под таблицей — калькулятор «сколько генераций
входит в тариф» и ответы на возражения: возврат, документы для юрлиц, права на изображения.

## 12. Что считается сделанным

Компонент/экран принимается, когда:

1. Реализованы все шесть состояний (§6).
2. Используются только токены; хардкод цветов отсутствует.
3. Проверен на 320 px и на 1440 px.
4. Проходит клавиатурный сценарий и проверку контраста.
5. Текст прошёл через `typo()` и словарь терминов.
6. Укладывается в бюджеты производительности.
7. Есть скриншот-тест на светлую и тёмную тему.
