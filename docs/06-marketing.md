# Маркетинг: позиционирование, каналы, воронка

ТЗ v1 называет аудиторию («бизнес и селлеры маркетплейсов») и упоминает
«страницы инструментов под SEO». Плана, по которому эта аудитория узнает
о сервисе, нет. Здесь — он.

---

## 1. Позиционирование

**Против кого конкурируем на самом деле.** Не против Midjourney — против
предметной фотосъёмки за 3 000 ₽ за карточку и против дизайнера на фрилансе.
Это меняет и сообщение, и цену: 25 кредитов против 3 000 ₽ — разговор
не о технологии, а об экономии.

**Формулировка:**

> Фотостудия для карточек товара без фотостудии.
> Загрузите фото на телефон — получите карточку по требованиям Wildberries за минуту.

Что здесь важно и чего нет в описании «сервис генерации изображений»:
названа задача, названа площадка, названы затраты (минута), назван вход (телефон).

**Что не говорим:** «на базе нейросетей», «ИИ нового поколения», названия моделей.
Аудитории всё равно, какая модель внутри, — ей нужна карточка, которая пройдёт модерацию WB.

### 1.1 Сегменты

| Сегмент | Задача | Готовность платить | Приоритет |
|---|---|---|---|
| Селлер WB/Ozon, 10–200 SKU | карточки, инфографика, сезонное обновление | 700–3 000 ₽/мес | **основной** |
| Малый бренд / производитель | контент для соцсетей и сайта | 1 500–5 000 ₽/мес | второй |
| SMM-специалист, агентство | контент для нескольких клиентов | 3 000–15 000 ₽/мес | третий, даёт BUSINESS |
| Любитель | эксперименты | 0–299 ₽ | не таргетируем, но конвертируем из органики |

Первый сегмент выбран не случайно: у него есть измеримая боль (карточка без фото
не продаётся), понятный измеримый результат (конверсия карточки) и он сам ищет
решение — то есть его можно перехватывать поиском, а не только рекламой.

## 2. Каналы

### 2.1 Программное SEO — основной канал

Люди ищут задачу, а не сервис: «удалить фон с фото товара», «фото для карточки
WB требования», «как сделать инфографику для маркетплейса». Каждый такой запрос —
отдельная страница с **работающим инструментом сверху** и ответом на вопрос ниже.

Структура страницы инструмента:

```
1. H1 = запрос дословно            «Удалить фон с фото товара онлайн»
2. Рабочий инструмент              загрузка → результат, без регистрации
3. Результат с вотермарком         CTA «Скачать без вотермарка» → регистрация
4. Пошаговая инструкция            3–5 шагов со скриншотами
5. Требования площадок             таблица размеров WB/Ozon/Avito
6. Частые вопросы                  FAQ + разметка FAQPage
7. Смежные инструменты             перелинковка
```

Требования, без которых pSEO превращается в дорвеи:

* Каждая страница даёт **работающий инструмент**, а не только текст.
* Уникальная часть — не менее 60 % объёма: своя инструкция, свои примеры, свои размеры.
* Разметка `HowTo`, `FAQPage`, `SoftwareApplication`; sitemap с приоритетами.
* Генерируем 30–50 страниц под реальные запросы из Вордстата, а не 5 000 комбинаций.
* Каждая страница отслеживается отдельно: трафик, конверсия в гостевую генерацию,
  конверсия в регистрацию. Не работающие через 3 месяца — переписываются или удаляются.

В схеме: модель `ToolPage` (slug, H1, связанный `Recipe`, тексты, метрики) —
контент-редактор без релиза.

### 2.2 Telegram

Основной канал прямой коммуникации в РФ:

* **Бот как полноценный продукт**, а не уведомлялка: фото → рецепт → результат,
  сквозной баланс с сайтом. Для селлера, который работает с телефона, бот
  может стать главным интерфейсом.
* **Канал** с практикой: разборы карточек, шаблоны на сезон, до/после.
  Не анонсы обновлений — их никто не читает.
* **Посевы** в сообществах селлеров: не баннер, а разбор конкретной карточки
  участника сообщества.

### 2.3 Партнёрства

Самый дешёвый канал для этой аудитории. Механика, ставки, атрибуция, выплаты
и антифрод — в `09-partners.md`; здесь только с кем работать.

* сервисы аналитики маркетплейсов (MPStats, Wildbox и подобные) — интеграция
  или взаимный обмен аудиторией;
* школы и курсы по работе с маркетплейсами — промокод для учеников
  (+10 % кредитов ученику, 20 % от платежей школе);
* профильные Telegram-каналы и блогеры — партнёрская ссылка с промокодом;
* агентства и фулфилмент-операторы — агентская схема: оптовая закупка
  кредитов со скидкой и суб-аккаунты клиентов;
* бухгалтерские и товароучётные сервисы для селлеров — совместные материалы.

Ограничение, о котором нужно знать до запуска: выплаты делаются **только
самозанятым, ИП и юрлицам**. Блогеру без статуса заплатить нельзя —
это сделало бы сервис налоговым агентом.

### 2.4 Платный трафик

Яндекс.Директ на конверсионные запросы («сделать фото товара для WB»),
ретаргетинг на не завершивших гостевую генерацию, VK Ads на сообщества селлеров.

Ограничение: тематика ИИ-генерации проверяется площадкой, правила уточняются
до запуска. Платный трафик включается **после** того, как органическая воронка
показала конверсию в оплату — иначе покупается трафик в неработающую воронку.

### 2.5 Публичная галерея

Работы пользователей (только с явного согласия, после модерации) — одновременно
социальное доказательство, источник длиннохвостого трафика и материал для
контент-маркетинга. Каждая работа — страница с промптом и кнопкой «повторить».

## 3. Воронка и метрики

```
Поисковый трафик / Telegram / реклама
        ↓  посещение страницы инструмента
Гостевая генерация           ← капча, дешёвая модель, вотермарк
        ↓  «скачать без вотермарка»
Регистрация                  ← результат переносится в аккаунт
        ↓  10 приветственных кредитов
Активация                    ← 3 генерации + скачивание в первой сессии
        ↓  кредиты закончились в середине задачи
Первая оплата
        ↓
Повторная покупка / подписка
```

| Переход | Целевой ориентир | Что чинить при провале |
|---|---|---|
| Посещение → гостевая генерация | 25 % | первый экран, скорость, капча |
| Гостевая → регистрация | 30 % | ценность «скачать без вотермарка», перенос результата |
| Регистрация → активация | 35 % | онбординг, качество рецептов по умолчанию |
| Активация → оплата | 15 % | момент упора в лимит, сохранение контекста |
| Первая → повторная оплата | 40 % | качество результатов, доля перегенераций |

**Северная звезда — скачанные результаты в неделю** (см. `04-product.md`).
Она объединяет качество, доступность и ценность: результат, который не скачали,
продукт не создал.

### 3.1 Аналитика

Яндекс.Метрика на фронте (Google Analytics не используем — вопрос локализации
данных, см. `05-legal-ru.md`) плюс **серверные события** в собственную таблицу:
браузерная аналитика режется блокировщиками, а по деньгам нужна точность.

Обязательные серверные события: `guest_generation`, `signup`, `first_generation`,
`activation`, `paywall_hit`, `payment_started`, `payment_succeeded`, `generation_failed`,
`goodwill_reroll`. У каждого — `utm`-метки первого касания, сохранённые при регистрации.

## 4. Лендинг

Структура, проверенная для этой аудитории:

| Блок | Содержание |
|---|---|
| 1. Первый экран | конкретный заголовок, поле промпта/загрузки **прямо здесь**, без «узнать больше» |
| 2. До/после | реальные товары, слайдер; не абстрактные арты |
| 3. Как это работает | 3 шага, 15 секунд чтения |
| 4. Рецепты под площадки | WB, Ozon, Avito, соцсети — узнаваемые задачи |
| 5. Экономия | «карточка у фотографа 3 000 ₽ / у нас 25 ₽» — прямое сравнение |
| 6. Отзывы | селлеры с указанием ниши и оборота, а не безымянные аватары |
| 7. Тарифы | три колонки, средняя выделена, калькулятор генераций |
| 8. Возражения | права на изображения, документы для юрлиц, возврат, безопасность фото |
| 9. Финальный CTA | повтор поля ввода |

Возражения — отдельный блок, а не мелкий шрифт. Для этой аудитории главные:
«а мои фото не утекут?», «примет ли WB такие изображения?», «дадите ли документы?».

## 5. Запуск

**Фаза 0 — закрытая бета (2–3 недели).** 20 селлеров из профильных сообществ,
1 000 кредитов бесплатно за развёрнутую обратную связь. Цель не выручка,
а список причин, по которым результат не идёт в карточку. Этот список определяет
каталог рецептов лучше любого исследования.

**Фаза 1 — тихий запуск.** Открытая регистрация, 10–15 SEO-страниц,
Telegram-канал. Метрика фазы: конверсия в активацию, а не число регистраций.

**Фаза 2 — рост.** Расширение до 50 страниц, посевы, партнёрства, реферальная
программа. Платный трафик включается только после подтверждённой окупаемости
органики.

**Фаза 3 — B2B.** Агентства и фулфилмент, API, закрывающие документы,
персональные тарифы.

## 6. Риски канала

| Риск | Смягчение |
|---|---|
| Зависимость от одного канала (SEO) | Telegram и партнёрства развиваются параллельно с первого дня |
| Отклонение рекламы из-за тематики ИИ | сообщение о задаче («фото для карточек»), а не о технологии |
| Приход крупного игрока с бесплатным тарифом | защита — рецепты под площадки и накопленные проекты, а не доступ к моделям |
| Сезонность маркетплейсов | годовая подписка со скидкой, перенос остатка кредитов |
| Рост курса и себестоимости | запас 15 % в цене, ежемесячная сверка, возможность поднять цену без релиза |
