# Эксплуатация: бэкапы, деплой, инциденты

Раздела эксплуатации в ТЗ v1 нет вовсе. Для сервиса, где база — единственный
источник истины по деньгам пользователей, это самый дорогой пропуск: остальные
дефекты стоят денег, этот стоит бизнеса.

---

## 1. Бэкапы

**Правило:** бэкап, восстановление которого ни разу не проверяли, бэкапом не является.

| Что | Как | Частота | Хранение |
|---|---|---|---|
| PostgreSQL WAL | `pgBackRest` → S3, PITR | непрерывно | 14 дней |
| PostgreSQL полный | `pgBackRest` full → S3 | ежедневно 04:00 MSK | 30 дней |
| Дамп биллинга | `pg_dump` → второй бакет у другого провайдера | ежедневно | 90 дней |
| S3 с результатами | версионирование бакета + lifecycle | непрерывно | по политике тарифа |
| Секреты и конфиги | зашифрованный архив вне сервера | при изменении | бессрочно |

Дамп биллинга уезжает **к другому провайдеру** сознательно: отказ или блокировка
основного аккаунта не должны уносить историю платежей.

Ежемесячно — учебное восстановление на чистый сервер с замером времени
и проверкой инвариантов (§7.1 ТЗ). Результат записывается; невыполненная проверка
считается инцидентом.

Целевые показатели: **RPO ≤ 5 минут** (WAL), **RTO ≤ 2 часа** (полное восстановление).

## 2. Деплой и миграции

**Порядок релиза:**

1. CI на PR: типы, линт (включая запрет `setGlobalDispatcher`), модульные,
   контрактные тесты, миграции на чистой базе.
2. Сборка образов с тегом коммита.
3. `migrator` — одноразовый контейнер, миграции обеих баз до старта приложений.
4. Поочерёдный перезапуск сервисов с ожиданием `/readyz`.
5. Дымовой тест на проде: генерация на mock-модели, тестовый платёж 1 ₽ с возвратом.

**Миграции — expand/contract, без исключений:**

```
Релиз N:   добавить колонку (nullable) → задеплоить код, пишущий в обе
Релиз N+1: перенести данные → код читает только новую
Релиз N+2: удалить старую колонку
```

Переименование колонки одним релизом на работающем сервисе даёт минуту 500-х
и потерянные платежи. Миграции, удаляющие данные, требуют ручного подтверждения.

**Откат:** предыдущий образ поднимается той же командой; миграции вперёд-совместимы
по построению (см. expand/contract), поэтому откат кода не требует отката схемы.

## 3. Мониторинг

Метрики `prom-client` на `/metrics` (только внутренняя сеть), сбор — Prometheus
в профиле `observability` либо внешний агент. Логи — pino JSON, сбор Vector,
хранение 14 дней. Ошибки — Sentry.

**Дашборд владельца — один экран:**

```
Выручка сегодня │ Расход USD сегодня │ Доля себестоимости │ Маржа
Генерации: успех / ошибка / в очереди │ Средняя латентность
Баланс kie.ai │ Баланс GenAPI │ Статус egress
Регистрации │ Активации │ Оплаты │ Конверсия
```

## 4. Алерты и runbook

У каждого алерта — действие. Алерт без действия отключается.

| Алерт | Порог | Первое действие |
|---|---|---|
| Egress недоступен | healthcheck 3 раза подряд | переключить пира; задачи уже в `DEFERRED` |
| Баланс провайдера низкий | < `WARN_USD` | пополнить; при `< STOP_USD` фолбэк включится сам |
| Доля ошибок высокая | > 10 % за 15 мин | проверить `ProviderState`, при необходимости отключить модель |
| Расхождение инвариантов | любое | **остановить начисления**, не чинить данные до разбора |
| Вебхук кассы не обработан | > 3 неудач | переиграть из `PaymentWebhook`, проверить подпись |
| Стоп-кран сработал | `dailySpentUsd > dailyBudgetUsd` | найти источник расхода, поднять лимит осознанно |
| Себестоимость отклонилась | > 20 % от `expectedCostUsd` | сверить прайс провайдера, обновить `Model` |
| Диск > 80 % | — | проверить ротацию логов и временные файлы |

**Отдельно про расхождение инвариантов.** Соблазн «поправить баланс руками»
максимален и вреден: расхождение — симптом бага, который продолжит работать.
Порядок: остановить начисления → снять дамп → найти причину по журналу транзакций →
исправить кодом → компенсировать пользователям транзакцией `MANUAL` с комментарием.

## 5. Регулярные задания

| Задание | Расписание | Что делает |
|---|---|---|
| Освобождение просроченных холдов | каждые 5 мин | `EXPIRED` для холдов терминальных генераций |
| Опрос балансов провайдеров | каждые 10 мин | `ProviderState`, алерты, фолбэк |
| Пересчёт `p50/p90` моделей | каждый час | честный ETA в интерфейсе |
| Доставка outbox | непрерывно | уведомления, `profile-sync` |
| Курс валют | 09:00 MSK | ЦБ; при отсутствии — последний доступный |
| Автопродление подписок | ежечасно | списание, `PAST_DUE`, уведомления |
| Ночная сверка инвариантов | 03:00 MSK | `ReconciliationRun`, алерт при расхождении |
| Отчёт по марже | 06:00 MSK | сравнение факта с `expectedCostUsd` |
| Удаление истёкших файлов | 04:30 MSK | S3 + БД по `Output.expiresAt` |
| Очистка `GuestQuota` | еженедельно | старше 30 дней |
| Учебное восстановление | ежемесячно | проверка бэкапа |

## 6. Сценарии отказов

| Отказ | Поведение системы | Действие человека |
|---|---|---|
| Упал egress | задачи → `DEFERRED`, кредиты в холде, честный статус | переключить пира |
| Упал провайдер | фолбэк по `Model.fallbackProvider`, тот же холд | проверить статус провайдера |
| Упали все провайдеры | платные генерации выключены, кредиты не списываются | сообщение в интерфейсе |
| Упал биллинг | генерации не стартуют (нет резерва), текущие завершаются | приоритетное восстановление |
| Упал контур генераций | **оплата продолжает работать** — ради этого сделано разделение | — |
| Кончилось место на диске | алерт на 80 % | проверить ротацию логов |
| Утечка `SERVICE_TOKEN` | — | ротация с двумя активными ключами, без простоя |
| Компрометация БД | — | ротация всех секретов, инвалидация сессий, уведомление по 152-ФЗ |

## 7. Что должно быть готово до первого платящего пользователя

Чек-лист. Ни один пункт не переносится «на потом»: каждый из них после первого
реального платежа стоит на порядок дороже.

- [ ] Бэкапы настроены и **восстановление проверено** на чистом сервере
- [ ] Ночная сверка инвариантов работает и присылает отчёт
- [ ] Стоп-кран (`SystemState`) реализован и протестирован
- [ ] Kill switch на egress проверен отключением туннеля
- [ ] Идемпотентность вебхуков проверена повтором одного события 100 раз
- [ ] Параллельные резервы проверены нагрузочным тестом (баланс не уходит в минус)
- [ ] Чеки 54-ФЗ отправляются, `receiptStatus` мониторится
- [ ] Оферта, политика ПДн, согласия опубликованы; уведомление в РКН подано
- [ ] Алерты приходят в Telegram и проверены учебной тревогой
- [ ] `/internal/*` недоступен снаружи — проверено с внешнего хоста
- [ ] Логи не содержат секретов и промптов — проверено выборкой
