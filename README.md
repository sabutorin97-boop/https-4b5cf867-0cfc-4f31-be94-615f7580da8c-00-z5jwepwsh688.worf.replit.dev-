# Окна Профигрупп — лендинг с квизом

Одностраничный сайт для оконной компании. Главный блок — квиз: посетитель
отвечает на шесть вопросов, получает подобранную комплектацию окна и оставляет
заявку на замер.

Цену квиз намеренно не считает — она известна только после замера, и обещать
цифру заранее значит обманывать клиента.

Стиль взят с сайта `ai-profigrup-studia`: тёмная тема, сине-фиолетовый градиент,
стеклянные карточки, сетка на фоне.

## Что внутри

| Файл | Что делает |
|---|---|
| `index.html` | Вся страница: шапка, первый экран, цифры, квиз, преимущества, этапы, вопросы, подвал |
| `styles.css` | Оформление и цветовая схема |
| `script.js` | Логика квиза, подбор комплектации, отправка заявки |
| `send.php` | Приём заявок на почту (нужен, только если на хостинге есть PHP) |
| `privacy.html` | Политика обработки персональных данных |
| `favicon.svg` | Иконка вкладки |

Сборка не нужна: ни npm, ни Node. Открывается двойным кликом по `index.html`,
на сервер заливается как есть.

## Что заменить перед запуском

Всё в одном месте — начало файла `script.js`, блок `SETTINGS`:

```js
var SETTINGS = {
  FORM_ENDPOINT: "",                          // куда отправлять заявки
  COMPANY: "Окна Профигрупп",
  CONTACT_PHONE: "+7 000 000-00-00",          // ваш телефон
  CONTACT_EMAIL: "zakaz@okna-profigrupp.ru",  // ваша почта
  TELEGRAM_URL: "https://t.me/sabutorin45"    // ваш Telegram
};
```

Телефон и почта из этих настроек сами подставятся в шапку, подвал и кнопки —
править их в `index.html` не нужно.

Отдельно стоит заменить:

- **Цифры в блоке статистики** — `index.html`, секция `<section class="stats">`:
  сейчас там 12 лет, 8 400 окон, 2 года гарантии, 1 день на установку.
  Поставьте свои настоящие.
- **Подарок к заказу** — `index.html`, карточка «Скидка за объём и подарок к заказу»:
  в тексте стоит заметная заглушка `[укажите: москитные сетки / откосы / подоконник]`.
  Замените на то, что дарите на самом деле.
- **Реквизиты в политике** — `privacy.html`: наименование организации, ИНН, адрес,
  дата редакции отмечены как `[наименование организации или ИП]` и подобные.
  Текст типовой, перед публикацией лучше показать юристу.
- **Домен** — `index.html`, теги `canonical` и `og:url`.

## Куда приходят заявки

Способ выбирается значением `FORM_ENDPOINT`.

**1. Пусто (как сейчас).** Заявка открывается письмом в почтовой программе
посетителя — ему остаётся нажать «Отправить». Работает без сервера, но часть
людей письмо не отправит. Годится, чтобы проверить лендинг, не настраивая ничего.

**2. Свой обработчик на хостинге — рекомендуемый вариант для Timeweb.**
Откройте `send.php`, впишите свою почту в `RECIPIENT` и адрес отправителя
в `SENDER` (обязательно на вашем домене, иначе письма уйдут в спам).
Затем в `script.js` укажите:

```js
FORM_ENDPOINT: "/send.php",
```

**3. Сторонний сервис.** Зарегистрируйтесь на Formspree и вставьте адрес формы:

```js
FORM_ENDPOINT: "https://formspree.io/f/ВАШ_КОД",
```

## Как залить на Timeweb

1. В панели управления откройте файловый менеджер или подключитесь по FTP.
2. Перейдите в каталог сайта — обычно `/public_html` или `/домен/public_html`.
3. Загрузите туда `index.html`, `styles.css`, `script.js`, `privacy.html`,
   `favicon.svg` и, если используете, `send.php`.
4. Откройте сайт в браузере и пройдите квиз целиком, чтобы проверить отправку.

Если заявки не приходят, проверьте в панели Timeweb, что для сайта включён PHP,
а адрес в `SENDER` действительно существует на вашем домене.

## Как менять содержимое

**Вопросы квиза** — массив `STEPS` в `script.js`. Каждый вопрос выглядит так:

```js
{
  id: "count",
  question: "Сколько окон нужно поменять?",
  options: [
    { value: "1", label: "Одно окно" },
    { value: "2-3", label: "2–3 окна" }
  ]
}
```

Добавили или убрали вопрос — прогресс и счётчик пересчитаются сами.

**Логика подбора** — функция `pickSolution` там же. Она получает ответы и
возвращает профиль, стеклопакет, фурнитуру, дополнения и объяснение «почему
именно так». Правила простые и читаются сверху вниз: например, «шум + магистраль»
даёт триплекс, «холод или частный дом» — шестикамерный профиль.

**Тексты страницы** — прямо в `index.html`, обычной правкой.

## Проверено

- Квиз проходится до конца, работают «Назад» и мультивыбор целей
- Разные ответы дают разные рекомендации
- Ответы сохраняются при случайной перезагрузке страницы
- Вёрстка не ломается на ширине от 360 px
- Анимации отключаются, если в системе включено «уменьшение движения»
